# core — composition root

Здесь собирается приложение: DI-провайдеры, HTTP-interceptors, guards, глобальная
обработка ошибок, конфигурация окружения.

Правила:

- может зависеть от `shared/**` и от **публичных API** фич (`features/<feature>`);
- не может залезать во внутренности фич (`domain/application/infrastructure/ui`);
- бизнес-логики здесь нет — только сборка и инфраструктурная обвязка уровня приложения.
