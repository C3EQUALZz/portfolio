# shared/kernel — чистое ядро

Building blocks, на которые опирается `domain` любой фичи: `Result`/`Either`,
branded-типы, базовые value objects, доменные ошибки, утилиты сравнения.

Правила:

- **никаких зависимостей вообще** — ни фреймворка, ни npm-пакетов, ни других слоёв;
- только чистые функции и типы, 100% детерминированность;
- покрытие тестами 95%+ (`npm run test:domain`), участвует в мутационном тестировании.
