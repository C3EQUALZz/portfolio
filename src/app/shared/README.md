# shared — переиспользуемое без бизнес-смысла

Три части:

- [`kernel/`](./kernel/README.md) — чистое ядро для домена: value objects,
  brand-типы, `Result`. Без фреймворка и без зависимостей наружу.
- `i18n/` — локализация: `provideI18n` (Transloco, словари `en.ts`/`ru.ts`)
  и `LocaleService` — текущая локаль сигналом.
- `testing/` — хелперы для спек (разворачивание `Result` и т.п.), без логики;
  импортируются из любого теста.

Правила:

- не знает ни о одной фиче — импорт из `features/**` запрещён;
- может зависеть только от `shared/**` и `shared/kernel/**`;
- если элемент нужен только одной фиче — его место в этой фиче, а не здесь.
